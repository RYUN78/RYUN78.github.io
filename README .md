# 🍢 みどり亭 注文・管理システム

居酒屋「みどり亭」向けのテーブルオーダー＆店舗管理システムです。
バックエンド不要・サーバーレスで動作するフロントエンドプロトタイプです。

---

## 📱 デモ

`index.html` をブラウザで開くと、お客様用「モバイルオーダー」と店舗用「管理システム」の入口が表示されます。インストール不要です。

---

## ✨ 機能一覧

### 📱 客側：モバイルオーダー（`customer/`）

#### 注文フロー
- **入店画面** — 大人・子供の人数を入力して入店（大人0名・子供のみはエラー）
- **メニュー画面** — カテゴリサイドバーで切り替え、商品をタップして数量選択
- **カート** — 数量変更・削除・注文確定
- **注文履歴** — 確定済み注文の一覧と合計金額

#### スタッフ呼び出し・会計
- **店員呼び出し** — 呼び出し中画面を表示
- **会計** — 卓番とお支払金額を表示

#### 時計・タイマー（全画面右上に常時表示）
- **日本時間（JST）** — 秒単位でリアルタイム表示
- **ラストオーダータイマー** — 残り時間をカウントダウン（30分以内でオレンジ点滅）
- **飲み放題タイマー** — 飲み放題プランを注文確定すると残り時間を表示（10分以内で警告）

### ⚙️ 店側：管理システム（`staff/`）

#### ログイン・権限
- **ログイン** — ユーザーID・パスワードで認証し、社員／アルバイトでメニューを振り分け
- **社員用メニュー／アルバイト用メニュー** — 権限ごとに操作可能な項目を表示
- **ログアウト確認**

#### 商品管理
- **商品追加** — 新規商品の登録と確認
- **商品削除** — 既存商品の削除と確認
- **商品編集** — 検索→編集フォーム→確認の3ステップ

#### テーブル管理
- **テーブル番号管理／QRコード発行** — 卓ごとのQRコードを生成（JsBarcode使用）
- **卓番変更** — 卓番の変更と確認
- **再発行** — QRコード・卓情報の再発行と確認

#### 注文・接客管理
- **売り切れ登録** — 商品検索→売り切れ設定の確認
- **注文入力** — QRスキャンを模したフォームでの注文登録と確認
- **注文取消** — 検索→対象一覧→取消確認
- **提供管理** — 検索→提供済み一覧→確認
- **注文状況一覧** — 卓ごとの注文状況を一覧表示
- **店員呼び出し一覧** — 呼び出し中の卓を表示
- **顧客台帳** — 来店した顧客情報の一覧

全画面で「戻る」操作の履歴スタックを管理しており、ログイン画面以外はワンタップで前の画面に戻れます。

## ⚙️ カスタマイズ

### ラストオーダー時刻を変える
`customer/clock.js` の先頭を編集してください。

```js
const LAST_ORDER_TIME = '22:00'; // ← ここを変更
```

### メニューを追加・変更する
`customer/data.js` の `MENU_DATA` を編集してください。

```js
"カテゴリ名": [
  { id: 99, name: "商品名", price: 500, img: "🍺", desc: "説明文" },
],
```

### 飲み放題プランを追加する
`customer/data.js` の `"飲み放題"` カテゴリに `nomihodaiMinutes` を設定してください。

```js
"飲み放題": [
  { id: 37, name: "飲み放題（90分）",  price: 1500, img: "🍻", nomihodaiMinutes: 90  },
  { id: 38, name: "飲み放題（120分）", price: 2000, img: "🍻", nomihodaiMinutes: 120 },
],
```

### 管理システムのログインユーザーを変える
`staff/admin_state.js` の `MOCK_USERS` を編集してください。

```js
const MOCK_USERS = [
  { id: 'staff01', password: 'pass01', role: 'staff'    }, // 社員
  { id: 'part01',  password: 'pass01', role: 'parttime' }, // アルバイト
];
```
